Let customers request returns and exchanges from My Account. Manage requests from an admin dashboard with customizable emails.

== Description ==

Zorem Returns is the premium version of Returns for WooCommerce. It adds licensed auto-updates from zorem.com on top of the same customer-facing return/exchange forms and admin fulfillment dashboard.

= Features =

* Customer-facing return and exchange request forms on the My Account page
* Guest returns (order ID + email verification, no account required)
* Admin fulfillment dashboard for reviewing, approving, rejecting and completing requests
* Cross-product exchanges with server-side price-difference calculation
* Store-credit coupons issued from exchange or return credit
* Restocking fee (product / category / global override chain)
* Fraud prevention: blocklist and rolling-window return limit
* Internal admin notes per request (private to support team)
* Warranty claim workflow (separate flow with its own dashboard)
* 14 customizable email templates with live-preview customizer
* WooCommerce HPOS compatible
* Automatic refunds for virtual products when the payment gateway supports it

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate the plugin through the "Plugins" menu in WordPress.
3. Go to WooCommerce > Returns Center to configure settings.
4. Enter your license key under WooCommerce > Returns Center > License to enable auto-updates.
