Contributors: BuildRightWeb
Requires at least: 6.0
Tested up to: 6.9
Requires PHP: 7.4
Stable tag: 1.0.5

Monthly medical research donation tracker, annual pledge progress, and community voting poll for Ion Peptide's mission page.

== Shortcodes ==
[ion_mission_page]
Full Ion-styled mission page layout, progress, monthly poll, and donation tracker.

[ion_donation_progress]
Annual pledge counter only.

[ion_donation_poll]
Monthly community poll only.

[ion_donation_tracker]
Donation history tracker only.

== Admin ==
Dashboard > Mission Donations
- Change monthly donation amount.
- Change annual commitment goal.
- Change campaign start month.
- Change poll question and organizations.
- Pause or open voting.
- Add donation records for the public tracker.
- Attach a donation receipt PDF URL to each donation record and display it on the public tracker.

== Monthly Rollover ==
The poll automatically resets when the site reaches a new month. The previous poll is archived internally, and the current month starts with fresh votes using the organization list saved in the admin panel.
